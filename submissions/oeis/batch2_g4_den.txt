NAME
Denominator of g_4(n), the maximum reciprocal sum of a 4-term arithmetic-progression-free subset of {1,...,n}.

DATA
1, 2, 6, 6, 30, 5, 5, 40, 360, 360, 360, 360, 360, 10920, 360, 720, 12240, 12240, 232560, 232560, 9520, 9520, 93933840, 351120, 270415600, 6224400, 7301221200, 7301221200, 7301221200, 7301221200, 89691647760, 3682355040, 40505905440

OFFSET
1,2

COMMENTS
g_4(n) is the maximum of sum(1/a for a in S) over all 4-term arithmetic-progression-free subsets S of {1,...,n}. Fractions are reduced. All 40 terms are backed by finite optimization proof replays.

EXAMPLE
For n=1, g_4(1)=1, so a(1)=1.

from fractions import Fraction

def terms(n=12, k=4):
    result = []
    for N in range(1, n+1):
        best = Fraction(0)
        suffix = [Fraction(0)]*(N+2)
        for v in range(N, 0, -1):
            suffix[v] = suffix[v+1]+Fraction(1,v)
        def search(v, chosen, score):
            nonlocal best
            if score+suffix[v] <= best:
                return
            if v > N:
                best = max(best, score)
                return
            if not any(all(v-j*d in chosen for j in range(1,k))
                       for d in range(1,(v-1)//(k-1)+1)):
                search(v+1, chosen | {v}, score+Fraction(1,v))
            search(v+1, chosen, score)
        search(1, set(), Fraction(0))
        result.append(best.denominator)
    return result

print(", ".join(map(str,terms())))
